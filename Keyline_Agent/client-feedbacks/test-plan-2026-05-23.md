# Aubrey — Test Plan (post feedback-01 fixes)

Covers everything we changed for [feedback-01](feedback-01.md), the test-call issues found in [call-transcripts.md](call-transcripts.md), and the OPENING redesign. Run these in a Retell web/test call. Most are 1–2 minutes each.

## Setup before testing

- **Caller-lookup is on phone (production).** Web test calls typically have no `from_number`, so Aubrey will treat the caller as **unrecognized** by default. That's what we want for Tests 1–6 and 8–9.
- **For Test 7 (returning caller),** you need a caller-board row that exists for the test phone with a populated **Caller Patient Name** column. Easiest: run Test 2 first, then immediately run Test 7 from the same caller.
- **What to inspect after each call:** the **ticket row** in Monday (board `18409649964`) and, where relevant, the **caller row** in Monday (board `18413254159`).

## Test 1 — Prospect sign-up (critical: prospect-route fix)

**Goal:** confirm the new OPENING exception sends sign-ups to PROSPECT INTAKE, not CAREGIVER MENU / PROSPECT STATUS CHECK.

**Caller script:**
1. "Hi, I want to sign up to get paid to take care of my mom."
2. *(if Aubrey asks anything clarifying, answer naturally; do not say you're a caregiver)*
3. Walk through whatever Aubrey asks for the 15-field prospect intake.

**PASS if:**
- ✅ Aubrey routes to **PROSPECT INTAKE** (not CAREGIVER - TOPIC MENU)
- ✅ The flow goes phone → **city and state** directly (no email step in between)
- ✅ Ticket created with `call_type: prospect`

**FAIL signals:** Aubrey asks the caregiver/client/case-manager identification question, or routes to PROSPECT STATUS CHECK (the Call 06 bug), or asks for email.
